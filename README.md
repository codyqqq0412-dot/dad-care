# 曾維杰 照護紀錄（看護填寫＋醫師報表）

這個資料夾有 3 個檔案：

| 檔案 | 用途 | 放在哪裡 |
|---|---|---|
| `index.html` | 網頁本體（看護填寫、翻身圖示、醫師報表、設定） | GitHub |
| `Code.gs` | 後端程式：檢查密碼、讀寫資料 | Google 試算表的 Apps Script |
| `README.md` | 這份說明 | GitHub（可有可無） |

## 資料存在哪裡？

所有填寫的資料都存在**你自己 Google 帳號裡的一個 Google 試算表**，GitHub 上只有網頁外殼，不含任何病歷資料。

- `data` 分頁：每天一列，網頁讀寫用，**請勿手動修改**。
- `每日總表` 分頁：每天一列、中印雙語欄位，可以直接看、列印或下載 Excel。
- `config` 分頁：網頁設定（胰島素規則、牛奶、翻身時間、流程）。

密碼經過加密（SHA-256 加鹽）後存在 Apps Script 的「指令碼屬性」，程式碼與 GitHub 上都不會出現密碼。

## 第 1 步：建立 Google 試算表與後端（約 10 分鐘）

1. 用電腦打開 https://sheets.new ，建立一個新的試算表，命名為「爸爸照護紀錄資料庫」。
2. 上方選單點 **擴充功能 → Apps Script**。
3. 把左邊 `程式碼.gs` 裡原本的內容全部刪掉，貼上 `Code.gs` 的全部內容。
4. 程式最上面兩個初始密碼已經填好（看護 ``、管理員 ``），不用再改。
5. 按 💾 儲存。
6. 上方函式下拉選單選 **setup**，按 **▶ 執行**。
7. 跳出授權視窗：選你的 Google 帳號 → 看到「Google 尚未驗證這個應用程式」→ 點 **進階** → **前往（不安全）** → **允許**。
   這是因為程式是你自己寫的，不是公開上架的 App，屬正常現象。
8. 下方「執行紀錄」出現「完成！」就成功了。回到試算表會看到 `data`、`config`、`每日總表` 三個分頁，十月的資料已經匯入。
9. **把兩個初始密碼改回空字串** `''`，再按儲存。密碼已經加密存好，不需要留在程式裡。

## 第 2 步：把後端發布成網址

1. Apps Script 右上角 **部署 → 新增部署作業**。
2. 「選取類型」旁的齒輪 ⚙ → 選 **網頁應用程式**。
3. 設定：
   - 說明：照護紀錄 API
   - 執行身分：**我**
   - 具有存取權的使用者：**所有人**
4. 按 **部署**，複製出現的「網頁應用程式網址」（`https://script.google.com/macros/s/……/exec`）。

> 「所有人」的意思是任何人都可以「連到」這個網址，但沒有正確密碼就讀不到、也寫不進任何資料。

## 第 3 步：把網址貼進網頁

用記事本（Windows）或文字編輯（Mac）打開 `index.html`，找到這一行：

```js
const API_URL = "PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE";
```

把引號裡的文字換成第 2 步複製的網址，存檔。

## 第 4 步：放上 GitHub 並開啟 GitHub Pages

1. 打開 https://github.com/codyqqq0412-dot/DFI
2. 點 **Add file → Upload files**。
3. 把 `index.html` 和 `README.md` 拖進去。如果想放在子資料夾，可以先建立資料夾 `care/`，避免和 DFI 其他檔案混在一起：上傳前在檔名前加 `care/`，或用 **Add file → Create new file** 輸入 `care/index.html` 再貼上內容。
4. 下方按 **Commit changes**。
5. 到儲存庫的 **Settings → Pages**：
   - Source 選 **Deploy from a branch**
   - Branch 選 **main**、資料夾選 **/(root)** → **Save**
6. 等 1～3 分鐘，網址會是：
   - 放在根目錄：`https://codyqqq0412-dot.github.io/DFI/`
   - 放在 care 資料夾：`https://codyqqq0412-dot.github.io/DFI/care/`

> **注意**：免費 GitHub 帳號只有「公開（Public）」的儲存庫可以使用 Pages。如果 DFI 是公司的私人儲存庫，建議另外新建一個公開儲存庫（例如 `care`）放這個網頁就好，網址會變成 `https://codyqqq0412-dot.github.io/care/`。網頁本身是公開的，但資料只能用密碼讀取。

## 第 5 步：設定看護的手機

1. 用看護手機的 Chrome 打開網址，輸入**看護密碼**，勾選「Ingat di HP ini 在這支手機記住密碼」。
2. Chrome 右上角 ⋮ → **加到主畫面**，之後就像 App 一樣點圖示打開。
3. 你自己用**管理員密碼**登入，會多一個 ⚙️ 設定分頁，可以：
   - 改胰島素規則、提醒範圍、量血糖時間
   - 改牛奶種類與時間表（例如 `09:00 | 桂格50鉻 Quaker | 250`）
   - 改翻身時間表（`telentang` 平躺、`kiri` 左側躺、`kanan` 右側躺）
   - 改看護每日流程與藥物
   - 更改看護密碼與管理員密碼

## 之後要更新程式時

- **只改網頁**（`index.html`）：在 GitHub 上點檔案 → ✏️ 編輯 → 貼上新內容 → Commit，1～3 分鐘後生效。
- **改後端**（`Code.gs`）：在 Apps Script 貼上新程式後，**部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**。這樣網址不變，不用改 `index.html`。

## 安全提醒

- 密碼至少 6 碼，不要用生日或電話號碼。看護換人時，記得到設定裡改看護密碼。
- 不要把 Apps Script 的「試算表」分享給不相關的人；需要給醫生看時，用網頁的「醫師報表」或下載 CSV 即可。
- 這是家用等級的保護（密碼＋HTTPS），適合家人與看護使用，不等同醫院的病歷系統。
